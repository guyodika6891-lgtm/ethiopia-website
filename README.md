# 🇪🇹 Ethiopia — Land of Origins

A beautiful, responsive website celebrating Ethiopia's history, culture, and heritage — including the Oromo Gadaa system, Irreechaa festival, and Afaan Oromo language.

## ✨ Features
- 🌙 Dark mode toggle (saved to localStorage)
- 💡 Rotating "Did You Know?" facts widget
- 🖼️ Photo gallery with hover effects
- 🗺️ Interactive OpenStreetMap embed
- 📬 Contact form with validation
- 🌿 Dedicated Oromo culture section
- 📱 Fully responsive design
